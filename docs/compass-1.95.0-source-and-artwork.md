# Understanding Compass — source and artwork record

Eight original recreational lessons, a fictional conversion workshop and 12 original self-check questions. This is independent training, not an RYA or MCA award. The eight SVGs in `assets/compass/` were created for Helmlore as schematic educational artwork, with no third-party image dependency. No real local variation or deviation is inferred from them.

## Primary reference check

- MCA Yacht Navigation and Radar Examination Syllabus: compass principles, variation and deviation. https://www.gov.uk/government/publications/officer-of-the-watch-yacht-written-examination-syllabuses/navigation-and-radar-examination-syllabus
- UKHO Admiralty Magnetic Variation Charts: geographically and temporally specific variation. https://www.admiralty.co.uk/charts/reference-and-plotting
- NOAA NCEI: magnetic declination and east-positive convention. https://www.ncei.noaa.gov/products/geomagnetic-data
- NOAA magnetic bearing help: true bearing equals magnetic bearing plus signed declination. https://www.ngdc.noaa.gov/geomag/calculators/help/bearingHelp.html
- RYA GPS and chartplotter guidance: distinguish heading and course over ground. https://www.rya.org.uk/network/running-racing/guidance-and-good-practice/racing-responsibilities/gps-evidence-in-hearings/

## Arithmetic convention

East is positive, west negative. Compass + deviation = magnetic; magnetic + variation = true. The worked values are C 082°, deviation 2° E, M 084°, variation 4° W, T 080°. Reverse conversion undoes each step. All results wrap to 000–359°. A real boat's deviation must be checked for the relevant heading; a single generic value is not a deviation card. Heading and COG alone cannot establish tidal stream.
