# Machinery artwork synchronisation

Approved October 2026 handbook artwork now supplies the diesel lesson illustrations and Boat Systems engine view. The dedicated `libraries/project-watch/machinery-artwork-20261018.js` registry holds image paths, dimensions and captions separately from UI code and questions. WebP copies preserve the public handbook crops and aspect ratios; the starting circuit remains SVG.

Original licensed component photographs and their credits remain in the repository as references. They are not presented as the newly illustrated engine, and legacy photograph hotspot coordinates are no longer applied to the new engine plate.

No question-bank, assessment, weather, account or navigation data changes.
