# Helmlore tidal artwork — build 1.93.1

Eight original AI-generated Helmlore teaching scenes are stored in `assets/tides/scenes/`. They are fictional illustrations, not chart reproductions or live predictions. Each lesson also links its separate, exact SVG teaching diagram under `assets/tides/`; the words, figures, calculations and reference-port rules remain in the external data library `libraries/project-watch/tides-1.93.1.js`.

| Lesson | Scene file | Prompt brief / intended visual |
|---|---|---|
| Tide cycle | `tide-cycle-1.93.1.webp` | Same sheltered stone harbour quay and ladder at low and high water, no boat or text. |
| Predictions | `tide-table-1.93.1.webp` | Recreational skipper checks a tidal prediction on a tablet against a chart and watch, no legible invented data. |
| Chart datum | `chart-datum-1.93.1.webp` | Side cutaway view of a motorboat, sea surface, seabed and visible under-keel water column. |
| Intermediate height | `tidal-curve-1.93.1.webp` | Same quay at three stages of a rising tide, with a fixed visual reference and no invented times. |
| Flood and ebb | `tidal-stream-1.93.1.webp` | Headland flow, eddies, sheltered water and coastal chop viewed from above. |
| Atlas reading | `stream-atlas-1.93.1.webp` | Skipper consulting an abstract stream-atlas display and a paper passage plan, no copied plate. |
| Set and drift | `set-drift-1.93.1.webp` | Overhead motorboat with a ghosted earlier position and water-flow texture to suggest displacement. |
| Passage window | `passage-window-1.93.1.webp` | Recreational cruiser approaching a sheltered harbour in late afternoon; fictional place and no exact prediction. |

Prompt set: premium widescreen British recreational marine teaching scenes in a restrained teal palette, without embedded text, numerical data, chart extracts, logos or watermarks. The lesson-specific subject and composition are described in the table. Built-in ImageGen was used. The first low/high-water candidate and its beached vessel were discarded; the boat-free harbour comparison is the published first scene. The generated triptych for intermediate height includes a boat touching bottom at low water, a useful visual cue for how quickly usable depth can change, but it is not a safe route or grounding instruction.

The generated scene assets are original to this project. Exact instructional geometry and calculations stay in the original SVG diagrams and lesson text. All are marked schematic training material, not for navigation. Artwork is referenced by file path from the external lesson library; no image data is embedded in `index.html`.
