# Annex 8 source figure crops

Ten PNG files reproduce the displayed mark examples from *CEVNI, European Code for Inland Waterways*, sixth revised edition (ECE/TRANS/SC.3/115/Rev.6), Annex 8. Source: [UNECE publication](https://unece.org/transport/documents/2022/02/standards/ecetranssc3115rev6). They are separate GitHub assets referenced by `libraries/cevni/annex8-official-plates-1.85.0.js`; no image data is embedded in the page code.

These are specific source examples. Annex 8 describes other forms, lights and placements for the same mark families. The ten former teaching SVGs remain in `assets/cevni/module03/` for historical reference but are no longer selected for this displayed library.
